INTRODUCTION TO TKINTER
What is Tkinter:
Tkinter is the standard GUI(Graphical User Interface) library for python. It provides a fast and easy way to create desktop applications with graphical elements like buttons, labels, textboxes, and more.

WHAT CAN YOU BUILD WITH TKINTER:
1. Desktop tools(e.g calculators, to-do apps)
2. form-based applications (e.g login systems)
3. Games and simple interactive programs
4. Drawing apps or visual tools
