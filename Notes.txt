INTRODUCTION TO TKINTER
What is Tkinter:
Tkinter is the standard GUI(Graphical User Interface) library for python. It provides a fast and easy way to create desktop applications with graphical elements like buttons, labels, textboxes, and more.

WHAT CAN YOU BUILD WITH TKINTER:
1. Desktop tools(e.g calculators, to-do apps)
2. form-based applications (e.g login systems)
3. Games and simple interactive programs
4. Drawing apps or visual tools

TKINTER LABEL WIDGET
The Label widget in python's tkinter library is used to display text or images in a GUI application. It is one of the most basic widgets, often used to provide information or captions

Key Features of Label
1. It is used to display static text or images
2. It is used to customize appearance using properties like font, color, size etc.
3.It can serve as a placeholder or provide feedback in an application.

Label syntax
Label(parent, text, options). options like font,bg,fg etc.

TKINTER FRAME WIZARD
A frame in tkinter is a container widget used to group and organize other widgets. It acts as a rectangular region on the screen where you can place other widgets such as buttons, labels,and text fields. Frames are espacially useful for creating complex layouts by dividing the window into manageable sections.

KEY FEATURES OF Frames
1. Container: Frames are primarily used as containers to organize widgets hierarchically.
2. Styling: You can customize the frame's appearance using properties like background color, border width, and relief styles.
3. Parenting: A frame can act as a parent to other widgets, allowing you to nest frames for complex layouts.

COMMON ATTRIBUTES
1. bg: backgground color of the frame
2. width and height: Set the dimensions of the frame
3. relief: Specifies the border style (e.g "flat","raised","sunken","groove","ridge")
4. borderwidth: Sets the width of the border.

fiil="y" fill frame to y-direction
side=LEFT put the frame to left side.


BUTTON WIDGET
In tkinter, a Button widget is used to create a button that users can click to trigger a specific action or event in a GUI application. The Button widget comes with several configurable options, allowing you to customize its appearance and behavior.

BUTTON WIDGET EXPLANATION
1. Text: The label displayed on the button.
2. Command: A function or method to be executed when the button is clicked.
3. width/height:Size of the button in terms of characters.
4. fg/bg: Foreground and background colors of the button.
5. font: The font style of the button text.
6. State: The state of the button, e.g NORMAL(default), DISABLED.

RAISED: It can be used as tk.RAISED OR relief="raised"
fill: It can be used as tk.BOTH for x and y or fill="y", fill="x"


TKINTER ENTRY WIDGET(ENTRY WIZARD)
The Entry widget in Tkinter is used to accept single-line text input from the user. It is commonly used for entring names, passwords, email, numbers, etc.

Syntax:

1. master: The parent container like root or a frame.
2. options: Configuration parameters to customize the widget such as font,bg,fg etc.

TEXT WIDGET (MULTI-LINE INPUT/DISPLAY)
The 'Text' widget in Tkinter allows users to enter or display multiple lines of text. It is like a notepad-style field and supports advanced formatting, tags, and scrolling.
Syntax:
text_widget = Text(master, options)
label = Label(root, text=text.get("1.0",END)) 1 stands for line 1 while 0 stands for zero character.


MESSAGE WIDGET IN TKINTER
The Message widget is similar to the label, but designed specifically for longer blocks of text. Unlike Label, it wraps text automatically, making it ideal for displaying multi-line static text like instructions or warnings.
Syntax:
msg=Message(master, text="Your long message here",options)
Practically: Two widgets used to display text are:
1. Label
2. Message
relief is used for formatting text.


LAYOUT MANAGEMENT IN TKINTER
Tkinter offers three main layout managers:
1. pack()
2. grid()
3. place()
You can also nest layouts using Frames inside Frames.

PACK()
The pack() geometry manager is one of the simplest ways to position widgets in a window. It automatically arranges widgets relative to each other in one of four directions: top, bottom, left, or right.
Basic Syntax:
widget.pack(options) options such as side(top,bottom,left,right),fill(expand widget to fill x,y,or BOTH),expand allow the widget to expand to fill any extra space in the geometry master, padx(Add horizontal padding),pady(Add vertical padding).


WHAT IS GRID LAYOUT IN TKINTER?
The grid() layout geometry manager arranges widgets in a tabular (grid-like) structure using rows and columns. It gives you fine control over where each widget appears.
Baisc Syntax:
widget.grid(row=0,column=0,options). options such as rowspan(It indicates how many rows the widget should span),columnspan(It indicates how many columns the widget should span),sticky(Aligns the widget N,S,E,W or combination of nsew),padx,pady,ipadx/ipady(Internal padding(space inside the widget)).

KEY ADVANTAGES OF grid()
1. It is better for form-style layouts (login forms,calculators, etc).
2. You can align widgets precisely using rows and columns.
3. Sticky helps to align widget inside its cell(e.g sticky=W aligns left).

IMPORTANT RULE ABOUT GRID()
Do not pack() and grid() in the same container (i.e, same frame or root window).
padx gives external space along x-axis while pady gives external space along y-axis.
row is vertically while column is horizontally.
